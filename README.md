# Blender Experiments

Mechanical objects and interactive 3D studies made in Blender. Each experiment has its own folder, with models, viewer code and project notes.

## Emerald

A mechanical beetle with emerald covers, champagne trim and detailed bearing joints.

- [Explore the interactive portfolio](https://itamecodes.github.io/blender-experiments/)
- [Download the model, film and portable viewer](https://github.com/itamecodes/blender-experiments/releases/tag/emerald-v1)
- [Project notes](experiments/emerald/README.md)
- [GLB model in the repository](experiments/emerald/models/Emerald-Beetle.glb)

Large film exports live in GitHub Releases, keeping repository history small. No license has yet been selected for the original artwork and model. Bundled dependencies retain their own licenses.
